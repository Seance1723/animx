# AnimX Studio User Guide (v3.10.0)

Welcome to AnimX Studio! This local visual application allows you to orchestrate the AnimX Core library visually without writing code.

## 1. What is AnimX Studio?
Studio is an **optional** set of development panels running directly in your browser. It parses `localStorage` to build animations cleanly. You do **not** need Studio in production; it generates `AnimX.timeline()` scripts and `data-ax-*` sequences that you inject into your projects.

## 2. Navigating Studio
The new v3.10.0 left-sidebar contains your entire workflow:
- **Home Dashboard:** Start new projects and view system stats.
- **Timeline Builder:** Sequence elements.
- **Creative Catalog:** View 300+ advanced primitives.
- **Settings:** Wipe local data or toggle Safe Mode.

## 3. Keyboard Shortcuts
Press `Ctrl/Cmd + K` at any time to open the quick Command Menu!
