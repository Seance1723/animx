# Animation Coverage Matrix (v3.12.0)

In v3.12.0, AnimX implemented a complete audit of all preset families to guarantee coverage across common web UI elements.

## Monitored Elements
- **Text & Typography**: Split text, kinetic text, rolling text.
- **Buttons & Cards**: Hover, click, focus, magnetic, tilt.
- **Nav & Links**: Active states, underlines, drawer reveals.
- **Tables & Lists**: Row staggers, empty state pop, fades.
- **Dashboards & KPI**: Number rolls, chart builds.
- **Modals & Drawers**: Scaling, sliding, backdrop fades.
- **Backgrounds**: Shifting gradients, aurora, grid pulses.
- **CMS**: Pre-configured recipes for hero headers, blog grids, and pricing tables.

You can view the real-time coverage scores in **AnimX Studio > Coverage Matrix**.
