# LTS Stability Guide

AnimX v3.11.0 is considered the Long-Term Support release for the v3.x lifecycle.

Our stability guarantees:
1. **Zero External Dependencies**: The core bundle will never require React, Vue, or GSAP.
2. **Backward Compatibility**: Old valid configs will not break.
3. **Performance First**: The Core API payload size remains under 20KB min/gzip.
