# Studio Quick Start

1. Open `dist/animx.studio.html` in your browser.
2. Read the initial Onboarding modal.
3. Click **Dashboard > Start New > Build Timeline**.
4. Add a Track, add a Step (e.g. Target `.hero-title`, Preset `fade-up`).
5. Click **▶ Play Preview**.
6. Export the generated JavaScript block to your codebase.
