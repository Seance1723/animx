# Capability Matrix

The element-first capability matrix answers:

For each element, what effects are available, what usage modes are supported, and whether each effect is ready for playground use?

Generated output:
- `dist/reports/animx-capability-matrix.json`

Required elements are always present, even when an element has zero effects:
- Text, Button, Link, Navigation, Card, Image, Gallery, Video, SVG, Icon, Logo, Background, Form Input, Modal, Toast, Tooltip, Accordion, Table Row, KPI Card, Chart, Section, Page Transition, CMS Block, Layout, Gesture, Physics, State

Counts are split by status and usage mode. Empty groups are intentional and prevent future modules from inventing unavailable effects.
