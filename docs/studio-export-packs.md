# Export Packs

AnimX Studio allows you to export your configured animations into the exact format your project needs.

## Available Packs
1. **HTML Class**: Basic `ax-*` classes.
2. **Data Attribute**: robust `data-ax-*` markup.
3. **JavaScript API**: Clean `AnimX.animate()` logic.
4. **CMS / No-Code**: `data-ax-recipe` and dynamic refresh notes.
5. **WordPress**: Guidance snippet for `wp_enqueue_script` + HTML.
6. **Webflow**: Custom embed ready HTML.
7. **React / Vue Snippets**: `useRef/useEffect` and `onMounted` documentation snippets.

Select the desired pack from the tabs below the preview canvas.
