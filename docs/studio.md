# AnimX Studio

AnimX Studio is a completely local, zero-dependency visual builder for AnimX.

## Features

- Visually browse and preview presets
- Adjust duration, delay, easing, and triggers
- Test animations on multiple included templates
- Preview responsively across desktop, tablet, and mobile
- Export clean HTML and JavaScript snippets
- Run automated accessibility and security audits

## How to use

Since AnimX Studio runs purely in the browser with no external dependencies, simply open the `animx.studio.html` file in your browser from the `dist/` directory, or if hosted on a CDN, navigate to that URL.

> [!NOTE]
> Studio uses `localStorage` to save your state across reloads. No data leaves your machine.
