# CMS & No-Code Pattern Packs (v3.14.0)

Every pattern exported from AnimX Studio includes a CMS-Safe snippet mode.

## WordPress / Webflow Integration
When you copy a pattern as CMS HTML, the system automatically translates JavaScript timelines into `data-ax` HTML attributes. This allows you to simply paste the attributes into the Custom Attributes panel in Webflow, or the HTML block in Gutenberg.
