# Motion System Planning

AnimX uses global Motion Styles to ensure consistency across your entire project. 

## Supported Styles:
- `smooth-professional`: 700ms duration, ease-out. Great for B2B.
- `bold-launch`: 900ms duration, spring easing. Great for creative sites.
- `minimal-subtle`: 400ms duration, linear. Great for data-heavy apps.
- `energetic-startup`: 500ms duration, spring. Great for mobile apps.
