# Studio Release Checklist

Before launching a new update or handing off an AnimX Package to a client, you should use the Release Assistant.

The Assistant generates a Markdown checklist evaluating:
1. Have versions been correctly bumped?
2. Did the local QA engine return a passing score (> 80)?
3. Are the exports validated and safe?
4. Are accessibility fallbacks in place?

You can copy the generated Markdown directly into your PR or release notes.
