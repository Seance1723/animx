# Complete Effect Taxonomy

AnimX groups animations by **Families** and **Categories**.

## Categories
1. **Entrance**: Effects designed for `data-ax` scroll reveals or page loads. (e.g., `fade-up`, `modal-pop`).
2. **Interaction**: Effects triggered by user input. (e.g., `button-hover`, `nav-link-underline`).
3. **Ambient**: Infinite looping effects. (e.g., `bg-aurora`).
4. **Data**: Number rolling, chart drawing. (e.g., `kpi-number-roll`).
5. **Recipe**: High-level orchestrations of multiple effects for CMS usage. (e.g., `cms-blog-grid-reveal`).
