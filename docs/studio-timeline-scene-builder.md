# AnimX Studio Advanced Timeline Scene Builder (v3.9.0)

The **Timeline Scene Builder** is a visual orchestrator inside AnimX Studio for creating complex, multi-step animation sequences without writing code.

## Key Capabilities
- **Visual Tracks**: Organize elements logically into Tracks and Groups.
- **Preview Canvas**: Test playback and timings on dummy DOM elements before exporting.
- **Export Formats**: Compile scenes down to zero-dependency Javascript `AnimX.timeline()` strings, or declarative HTML data attributes where applicable.
- **100% Local**: Everything is stored securely in your browser's `localStorage`. No cloud sync, no accounts, no external dependencies.
- **Safe Imports**: The engine runs strict schema validation and strips malicious strings to prevent Prototype Pollution or XSS injections.
