# AnimX Studio Preset Pack Manager (v3.8.0)

The **Preset Pack Manager** is a zero-dependency, local-first system within AnimX Studio. It allows teams to organize and distribute reusable, project-specific animation libraries.

## Features
- **Local Storage**: All packs are saved to your browser's `localStorage`.
- **Validation Engine**: Prevents importing malformed JSON or unsafe JavaScript injection vectors (like Prototype Pollution).
- **Import/Export**: Move preset packs across projects securely as JSON files without requiring a cloud backend.
- **Zero Core Footprint**: Does not bloat `animx.min.js`.

To access the Manager, launch AnimX Studio and click the **Preset Packs** tab.
