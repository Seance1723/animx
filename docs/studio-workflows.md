# Studio Workflow Automation

AnimX v3.2.0 introduces Workflow Automation. Instead of animating elements one-by-one, you can select a workflow (like "SaaS Landing Page Setup" or "CMS No-Code Setup") and AnimX will automatically generate the required sections, assign the optimal motion style, and apply accessible defaults.

## How to use:
1. Open AnimX Studio.
2. Click on the "Workflows" tab in the top navigation.
3. Select a workflow preset and click "Run".
4. The studio will switch to Project mode and populate your sections.
