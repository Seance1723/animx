# Preset Reference

AnimX v3.42.0 Documentation.

This document covers preset reference.

> **Zero Dependency:** AnimX requires no external libraries.

## v3.42 Text Reveal Presets

Ready text reveal presets include `text-mask-up`, `line-mask-up`, `word-fade-up`, `char-wave`, `char-domino`, `char-elastic-pop`, and `paragraph-line-build`.

Use them as classes, data attributes, or through `AnimX.text()`. Registry metadata is available through `AnimX.getEffectsByElement("text")`.
