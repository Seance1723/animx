# Dist File Guide

- `animx.css` / `animx.min.css`: Core CSS framework.
- `animx.js` / `animx.min.js`: Core runtime (IIFE format for browser `script` tags).
- `animx.esm.js` / `animx.esm.min.js`: Core runtime (ESM format for bundlers).
- `animx.core.js` / `animx.core.esm.js`: Stripped down engine without preset heavy metadata.
- `animx.demo.html`: Basic smoke-test visual verification file.
