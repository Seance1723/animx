# Ecommerce Animation Pack (v3.14.0)

Built for high-performance storefronts, focusing on product imagery and Add-to-Cart prominence.

## Included Patterns
1. **Product Detail Motion (`ecommerce-product-detail-motion`)**: An image zoom reveal combined with text staggers.
2. **Product Grid (`product-gallery-reveal`)**: Lazy-loaded reveals for dense thumbnail grids.
