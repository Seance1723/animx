# AnimX Delivery Kits

A Delivery Kit is a comprehensive JSON payload generated by AnimX Studio (v3.7.0+). It packages your entire project schema, all handoff documentation, and QA summaries into a single portable file.

## Why Delivery Kits?
Instead of sending clients multiple scattered files, you can provide one `animx-delivery-kit.json`. This ensures:
1. Developers have the exact Animation Map.
2. QA Teams have the Accessibility and Security summaries.
3. CMS Editors have the Preset Inventory to know which classes to apply.

## Kit Structure
```json
{
  "version": "3.7.0",
  "projectName": "My Project",
  "documents": {
    "clientGuide": "...",
    "developerGuide": "...",
    "animationMap": "...",
    "presetInventory": "...",
    "qaSummary": "..."
  }
}
```

Use the **Delivery Kit** tab in AnimX Studio to generate and download these files securely without server dependencies.
