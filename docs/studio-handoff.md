# AnimX Studio Handoff Documentation

AnimX v3.7.0 introduces the ability to generate zero-dependency Markdown documentation directly from your visual projects.

## Included Guides
- **Client Motion Guide**: High-level explanation of the project's animation strategy, written in non-technical terms for stakeholders.
- **Developer Implementation Guide**: Code snippets for `<script>` and `<link>` tags, plus an overview of the data attribute API.
- **CMS Editor Guide**: Best practices for content editors on applying AnimX classes to dynamic rich text.
- **WordPress Handoff Guide**: Enqueue scripts and Gutenberg integration notes.
- **Webflow Handoff Guide**: Custom code setup and custom attribute application.

## Usage
Inside AnimX Studio, navigate to the **Handoff Documentation** tab, select your platform, and click Generate. You can copy the Markdown or download it instantly.
