# Compatibility Matrix (v3.11.0)

AnimX v3.11.0 guarantees backward compatibility across all major v1, v2, and v3 APIs.

- `AnimX.animate()`: Fully Compatible
- `AnimX.timeline()`: Compatible (Deprecation warning for flat arrays)
- `AnimX.scroll()`: Fully Compatible
- `AnimX.accessibility()`: Fully Compatible
- **Preset Aliases:** Maintained (e.g., `fadeUp` resolves to `fade-up`)
