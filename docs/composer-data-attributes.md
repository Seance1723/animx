# Composer Data Attributes

AnimX v3.15.0 introduces two new core attributes:

## `data-ax-variant`
Applies a pre-registered JSON variant.
`<div data-ax-variant="premium-card-hover"></div>`

## `data-ax-compose`
Allows quick inline chaining using a pipe delimiter.
`<div data-ax-compose="fade-up | card-lift"></div>`
