# AnimX Studio Builder Guide

The Studio provides several specific building modes tailored to different features of the AnimX Core.

## Modes

1. **Preset Mode (Default)**: Browse the massive library of core presets and instantly apply them to templates.
2. **Timeline Mode**: Build sequential steps using `AnimX.timeline()`.
3. **Stagger Mode**: Preview staggered layout reveals and card grids.
4. **Text Mode**: Test split-text reveals (characters, words, lines).
5. **SVG Mode**: Preview path-following, drawing, and morphing.
6. **Layout Mode**: Preview complex layout transitions and shared element swaps.
7. **Gesture Mode**: Test touch interactions like swipe, drag, and hold.
8. **CMS/No-Code Mode**: Preview robust data-attribute driven recipes perfect for WordPress, Webflow, and other CMS platforms.

Select a mode from the top toolbar to switch contexts.
