# AnimX v3.6.0 Creative Animation Catalog

AnimX v3.6.0 massive expands the animation catalog without requiring any third-party dependencies (like GSAP or Anime.js). We use a combination of native Web Animations API and CSS variable modifiers to achieve high-performance creative effects.

## The Strategy: Primitives + Modifiers
Instead of bloating the codebase with 2,000 unique presets, we built the Creative Catalog on **Primitives**.
For example, the `roll` primitive handles interval-based text swaps. Modifiers like `-up`, `-down`, `-left`, `-right` dictate the transform direction.

## Categories Available:
1. **Advanced Text Effects** (Rolling, Kinetic, Scroll Typography)
2. **Component Effects** (Buttons, Cards, Media Reveal)
3. **Scroll & SVG** (Progress reveals, Path Drawing)

You can explore these directly inside the new **Creative Catalog** tab within AnimX Studio.
