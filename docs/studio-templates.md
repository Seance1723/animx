# AnimX Studio Templates

AnimX Studio ships with a variety of built-in structural templates to help you test animations in context.

## Available Templates

- **Hero Section**: A standard large header, subtitle, and CTA button.
- **Card Grid**: A responsive grid of feature/pricing cards.
- **Text Engine**: Large typography designed for testing split-text animation.

Select a template from the left sidebar to swap the active canvas. You can click any individual element within a template to target it with the inspector.
