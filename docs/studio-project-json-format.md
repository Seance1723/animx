# Project JSON Format

You can export your entire project state as JSON.

```json
{
  "version": "3.2.0",
  "projectId": "proj-123",
  "name": "Untitled Project",
  "type": "custom",
  "motionStyle": "smooth-professional",
  "sections": []
}
```

This file can be loaded locally to resume work later. It contains no executable scripts.
