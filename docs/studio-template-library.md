# AnimX Studio Template Library

AnimX v3.1.0 ships with a massive built-in template library in the Studio. 
You can browse over 40+ templates across categories like:
- Hero Sections
- Features
- Pricing
- Stats
- Testimonials
- CMS / No-Code

Click on any template in the left sidebar to load it into the canvas. You can then click specific elements to modify their animations, duration, and easing.
