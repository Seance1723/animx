# AnimX Website

The official, zero-dependency demo and playground experience for AnimX.

## Commands
\`\`\`bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
\`\`\`

## Architecture
Built with React + Vite. Uses local AnimX dist files to preview real animations without external dependencies.
